# Xiso Extractor

An Android app to browse, preview, and extract original Xbox disc images (xiso/XDVDFS) on your device.*

## Features
- Browse ISO contents like a regular folder, complete with file size and number.
- Preview files: text, image (png/jpg/bmp/gif/webp), or hex for binary files.
- Select multiple files and extract them, or extract them all.
- Search for files throughout the ISO, copy paths, and view file info.
- Supports regular xiso and redump ISOs (XGD1/XGD2/XGD3), auto-detected.
- Can be opened via "Open with" in the file manager.

## Install
Download the latest `XisoExtractor.apk` from the **Releases** page and install it on your phone (allow installation from unknown sources if prompted). Android 7.0 (API 24) and above.

 ## Privacy
The app **does not use the internet, and does not collect data**.
Files are selected via the Android system file picker.

## Bring your own ISO
This repo does not contain any games, ISOs, or dumps.
Only use copies of discs that you legally own.
